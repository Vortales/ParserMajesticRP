# ParserMajesticRP

Парсер форума Majestic RP (XenForo + UIX-тема): сканирование структуры форума,
парсинг тем (текст + OCR изображений) и генерация docx-баз знаний для ИИ —
«Общие правила» + отдельная база под каждый сервер.

## Версии

| Версия | Код | Данные | Статус |
|---|---|---|---|
| 1.14 | `ultiparser1.14.py` | `ultiparser1.14/` (бывшая `ServerParser/`) | Заморожена, рабочая. Порядок слоёв: промт → общие → сервер + хвост `===КОНЕЦ ОТВЕТА===` |
| 1.15 | `ultiparser1.15/ultiparser1.15.py` | `ultiparser1.15/forum.majestic-rp.ru/` (создаётся/сюда мигрируется) | Актуальная. Порядок слоёв: общие → сервер → **промт в самом низу**, хвост удалён |

Подробности по 1.15: `ultiparser1.15/README.md`, разбор кода: `ultiparser1.15/АНАЛИЗ_ОШИБОК.md`.

## Быстрый старт (1.15)

```
cd ultiparser1.15
python migrate_data.py     # один раз: перенос структуры/галочек/конфига из 1.14
python ultiparser1.15.py   # запуск (зависимости ставятся сами, нужен Chrome)
```

Рабочий цикл в программе: `🔑 Войти` → `🔍 Сканировать` (Этап 1) →
пометки «Общие правила»/«Сервер» + чекбоксы → `Этап 2` → `🚀 Сформировать документы`.
