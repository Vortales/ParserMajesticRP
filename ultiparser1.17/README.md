# ultiparser 1.17 — транспорт, история изменений, картинки

Полный парсер на Tkinter: сканирование структуры форума Majestic RP →
скачивание тем → формирование DOCX (правила сервера / правила гос. структур).

## Что нового в 1.17 (по итогам анализа реальных логов)

Анализ двух боевых логов (`Сканировать выбранные`, `Сформировать документы`):
полный разбор — в [АНАЛИЗ_ЛОГОВ.md](АНАЛИЗ_ЛОГОВ.md).

**Транспорт (быстрый HTTP-клиент):**
- Cookie-jar приводится к каноническому виду при каждом запросе (порча
  `Cookie2`/`Cookie:`-строк из браузера больше не убивает сессию);
- разделены причины отказа fast-клиента: `redirect_login` (редирект на
  /login/) и `login_form` (форма входа в HTML), для каждой — свой счётчик
  в статистике и автодамп HTML в `logs/fast_refused/`;
- деплой куки из браузера (`cookie_harvest`) теперь повторяет запрос через
  fast вместо вечного fallback на браузер;
- адаптивный cooldown после отказов: 300 → 600 → 1200 → 1800 с (сброс при
  первом же успехе), причина видна в логе;
- явные ветки для HTTP 403, 429, 5xx и таймаутов; 404 грозы больше нет;
- статистика транспорта: успех/отказ/причины + окно cooldown.

**История изменений (новый виджет «📜 История»):**
- попапы `Отчет по темам` после этапов 2 и 3 удалены — вместо них кнопка
  «📜 История» с бейджем непрочитанных изменений;
- слева — список `название_темы`, справа — полный хронологический журнал
  по теме: дата и время каждого изменения, блоки **БЫЛО / СТАЛО**,
  разделители постов, сортировка новые→старые / старые→новые;
- хранение: `data/history.json` (события `new/changed/found/gone`,
  дедупликация повторов, лимиты: 100 событий на тему, 200 строк diff,
  500 символов на строку); старые `prompt_*.txt` не трогаются;
- diff-диагностика: честное объяснение «без БЫЛО/СТАЛО»
  (смена автора/даты, пробелы, замена картинки, метаданные).

**Картинки и OCR:**
- сквозная нумерация `Изображение #N`, спиннер не висит на пропущенных;
- дедуп по URL (повторная картинка — «дубль URL — из памяти», 0 HTTP);
- негативный кэш: мёртвый URL качается максимум 1 раз;
- гейты OCR: пропуск файлов < 1500 байт и картинок < 24×24;
- кэш OCR по SHA-256 содержимого (`images/.ocr_cache.json`);
- бюджеты: общий дедлайн 12 с, лимит промахов fallback 3 шт.

**Мелочи:**
- русские plural-формы везде («1 пост», «2 поста», «5 постов»);
- прогресс-бар ограничен 100% (исправлен артефакт «120%»);
- Этап 1 пишет честный итог: сколько разделов просканировано;
- scrollbar'ы в дереве и истории (не только колесо мыши).

## Быстрый старт

```bat
cd ultiparser1.17
python ultiparser1.17.py
```

Зависимости ставятся сами при запуске (нужен Chrome).

Первый запуск: введите логин/пароль форума → **💾 Сохранить**.
Дальше: **1. Сканировать разделы** → выбрать темы → **2. Скачать темы** →
вкладка «Документы» → **Сформировать документы**.

## Перенос данных из 1.16

```bat
cd ultiparser1.17
python migrate_data.py            :: ищет ultiparser1.16 рядом
python migrate_data.py --src <путь к ultiparser1.16>
```

Копируются структура, чеки, конфиг, куки, даты тем, **история**,
кэш и картинки. Также умеет мигрировать напрямую из 1.14/1.15.

## Тесты

```bat
cd ultiparser1.17\tests
python test_transport.py    :: T1–T7: jar, отказы, harvest-retry, cooldown, parity
python test_features.py     :: plurals, история, diff, картинки, OCR, docx, стражи
```
