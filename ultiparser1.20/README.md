# ultiparser 1.20 — почему браузер + фильтры ключевых слов

Полный парсер на Tkinter: сканирование структуры форума Majestic RP →
скачивание тем → формирование DOCX (правила сервера / правила гос. структур).

## Почему всё время браузер (разбор)

Факты из лога: куки отправляются (`cookies: 8, xf_user: есть` — это
доказано и тестом), но форум каждый раз присылает страницу с формой
входа. Возможны две причины:

1. **Сессия мертва на стороне форума.** Файл cookies выглядит живым
   (`xf_user` есть, срок в будущем), но remember-токен уже не признаётся
   сервером — и каждый быстрый запрос получает гостевую страницу.
   Лечение: свежий «🔑 Войти» **с галочкой «Запомнить меня»**, затем
   «🍪 Проверить cookies» должен показать «Быстрый путь РАБОТАЕТ».
2. **Форма входа встроена в тему оформления.** Страница на самом деле
   ваша (есть меню аккаунта и контент), но детектор видел форму входа
   и браковал страницу. Это чинится само в 1.20 (см. ниже).

Что делает 1.20 для обоих случаев:

- **доверие маркерам входа**: если на странице есть сильные маркеры
  (меню аккаунта, ссылка выхода) И ожидаемый контент (темы/посты),
  страница принимается быстрым путём, а форма игнорируется
  (`…КБ (маркеры входа есть, форма проигнорирована)`); счётчик
  `fast_trusted` в статистике транспорта;
- **разбор каждого отказа**: в причине теперь видно
  `маркеры входа: нет / только слабые / есть, но нет контента`,
  в лог пишется заголовок страницы;
- **полные дампы** `logs/fast_refused/*.html` (было 8 КБ) с разбором
  в шапке — отказавшую страницу можно открыть в браузере и увидеть
  глазами, что прислал форум;
- **«🍪 Проверить cookies»** тоже умеет доверять маркерам и показывает
  разбор (заголовок, число маркеров, контент).

Безопасность: гостевая страница без маркеров по-прежнему идёт
в браузер; страница с маркерами, но без контента — тоже (защита
от «нет прав»).

## Фильтры ключевых слов

У каждого слова для тем и разделов теперь два фильтра:

- **☑ целое** — «закон» выбирает «Закон "О…"», но игнорирует
  «законодательство» и «законопроект»;
- **позиция**: «везде» / **«в начале»** / «в конце» —
  «закон "О…"» подходит, а «тут закон» — нет (для «в начале»).

Старые настройки (просто слова) работают как раньше: подстрока, везде.
Исключения (1.19) оставлены широкими специально: там широта = надёжность.

## Быстрый старт

```bat
cd ultiparser1.20
python ultiparser1.20.py
```

Зависимости ставятся сами при запуске (нужен Chrome).

## Перенос данных из 1.19

```bat
cd ultiparser1.20
python migrate_data.py            :: ищет ultiparser1.19 рядом
python migrate_data.py --src <путь к ultiparser1.19>
```

Копируются структура, чеки, конфиг, куки, даты тем, **история**,
кэш и картинки. Также умеет мигрировать напрямую из 1.14–1.18.

## Тесты

```bat
cd ultiparser1.20\tests
python test_transport.py    :: T1–T12 (+trust-markers, analyze)
python test_features.py     :: plurals, история (H1–H5), исключения (E1),
                            :: матчер слов (E2), diff, картинки, OCR,
                            :: docx (X1/X2), стражи
```

## Структура папки

| Файл | Назначение |
