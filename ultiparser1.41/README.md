# ultiparser 1.41 — Последовательная очередь запросов к форуму, защита от банов и дедупликация тем

## Новое в версии 1.41:
1. **Последовательное скачивание тем с форума в «Выборочном парсере»:**
   - Полностью устранён параллельный шквал запросов к сайту (убран пул `ThreadPoolExecutor` для страниц тем форума).
   - Запросы страниц тем форума выполняются **строго последовательно** с естественными задержками (`PAGE_DELAY_MIN`–`PAGE_DELAY_MAX`), как в «Этапе 3: Сайт».
   - Защита форума (Cloudflare / Rate Limit) больше не срабатывает и не включает паузу «Форум отдыхает».

2. **Очередь связанных ссылок DFS (`collections.deque`):**
   - Все новые найденные ссылки на темы форума (включая ссылки из текста, сносок и связанных постов) помещаются в конец очереди.
   - Ссылки проверяются на уникальность — дублирующие ссылки не добавляются повторно в очередь.

3. **Мгновенное копирование уже существующих тем (Zero-Network re-use):**
   - Перед обращением к сети парсер проверяет наличие темы:
     1. В уже сохранённых темах текущего сеанса.
     2. В целевой папке `Темы/` и её подпапках.
     3. В глобальном кэше тем проекта (`/Темы`).
   - Если тема уже была спарсена ранее, её `.json` файл мгновенно копируется в целевую структуру без единого сетевого запроса к форуму.

4. **Асинхронные рабочие потоки для сторонних ресурсов:**
   - Сторонние картинки (OCR) и документы (Google Docs / Яндекс.Диск) продолжают скачиваться и обрабатываться в параллельных фоновых очередях без задержек.
