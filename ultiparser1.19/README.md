# ultiparser 1.19 — хвост, чистка, история по слоям, проверка cookies

Полный парсер на Tkinter: сканирование структуры форума Majestic RP →
скачивание тем → формирование DOCX (правила сервера / правила гос. структур).

## Что нового в 1.19

**Итоговый файл:**
- в самый конец добавлен хвост-приказ: «Действую согласно промта
  в начале файла и в конце ответа всегда отвечай ===КОНЕЦ ОТВЕТА===.»;
- символы `=` и `_` вычищаются из всего документа, кроме маркера
  `===КОНЕЦ ОТВЕТА===` (он остаётся нетронутым, разделители `====`
  исчезают); двойные пробелы после чистки схлопываются повторным
  циклом «пока замен не будет 0».

**Промт 1.9** (`promt 1.9.txt` в папке версии — доработка `promt 1.5.txt`):
форма ответа сохранена; усилены точность, краткое цитирование статей
(номер + название + 1–2 фразы дословно) и честность границ ответа
(«суть здесь и сейчас», без галлюцинаций). Чтобы применить: скопируйте
файл в папку данных и выберите через «📄 Выбрать».

**История по слоям:**
- переключатель «📜 Общие» / «🖥 Сервер» + выбор сервера из списка —
  темы разных серверов больше не смешиваются (привязка пишется
  в события при формировании документов; старые записи без привязки
  видны в обоих слоях);
- кнопка «🚫 Исключения…» — слова-исключения (по аналогии с ключевыми):
  тема со словом в названии скрывается из списка слева в обоих слоях;
- в журнале видно «Слой: …» у каждого события; выбор слоя запоминается.

**Ключевые слова:** секция «🚫 Исключения» — если слово есть в названии
темы или раздела (например, «Отмененные законопроекты»), автоотметка
не ставится. В логе сканирования такие темы помечаются
«⏭ Пропущена (слово-исключение)».

**Потоки:** значение спинбокса «Потоков» сохраняется в конфиг (`workers`)
и восстанавливается при запуске.

**Быстрый путь (cookies) — диагностика и починка:**
- вывод такой: механика отправки куки исправна (проверено тестом —
  `xf_user` реально уходит в заголовке), а «форма входа в HTML»
  означает, что форум не признал сессию (сессия мертва на стороне
  форума, хотя файл cookies выглядит живым);
- новая кнопка «🍪 Проверить cookies» — делает пробный запрос быстрым
  путём и пишет вердикт: работает / сессия мертва / нет куки;
- такая же проверка автоматически выполняется после каждого входа;
- при входе без `xf_user` — предупреждение, что вход был без галочки
  «Запомнить меня» и быстрый путь умрёт с закрытием браузера;
- в причине отказа теперь видно состояние куки
  («форма входа в HTML (119 КБ; cookies: 8, xf_user: НЕТ) → браузер»);
- свежие куки из браузера сразу сохраняются в файл, а не только в память.

## Быстрый старт

```bat
cd ultiparser1.19
python ultiparser1.19.py
```

Зависимости ставятся сами при запуске (нужен Chrome).

## Перенос данных из 1.18

```bat
cd ultiparser1.19
python migrate_data.py            :: ищет ultiparser1.18 рядом
python migrate_data.py --src <путь к ultiparser1.18>
```

Копируются структура, чеки, конфиг, куки, даты тем, **история**,
кэш и картинки. Также умеет мигрировать напрямую из 1.14–1.17.

## Тесты

```bat
cd ultiparser1.19\tests
python test_transport.py    :: T1–T10 (+verify, persister, cookie diag)
python test_features.py     :: plurals, история (H1–H5), исключения (E1),
                            :: diff, картинки, OCR, docx (X1/X2), стражи
```
