# ultiparser 1.18 — промт наверх, документ одним абзацем

Полный парсер на Tkinter: сканирование структуры форума Majestic RP →
скачивание тем → формирование DOCX (правила сервера / правила гос. структур).

## Что нового в 1.18

По итогам тестирования 1.17:

- **Промт возвращён в самый верх** — снова слой 1: порядок слоёв
  в документах стал `ПРОМТ → ОБЩИЕ ПРАВИЛА → ЗАКОНОДАТЕЛЬНАЯ БАЗА`
  (в 1.15–1.17 промт был в самом низу);
- **Финал — всё в одну кучу без абзацев**: готовый документ схлопывается
  в один сплошной абзац — дословный аналог Word-замены `^p` → `" "`
  (1 пробел), цикл повторяется, пока замен не будет 0; кратные пробелы,
  табы и переводы строк тоже схлопываются в одиночные пробелы;
- технические отчёты по темам (`_save_topic_docx`, блоки Было/Стало)
  намеренно оставлены структурированными — это читаемые людьми отчёты,
  а не база для ИИ.

## Что было в 1.17 (кратко)

Анализ боевых логов: канонизация cookie-jar, разделение отказов fast
(`redirect_login`/`login_form` + дампы HTML), harvest-retry, адаптивный
cooldown 300→1800, кнопка **📜 История** вместо попапов, дедуп/гейты
картинок и OCR, plural-формы, кламп прогресса. Подробности —
в [АНАЛИЗ_ЛОГОВ.md](АНАЛИЗ_ЛОГОВ.md).

## Быстрый старт

```bat
cd ultiparser1.18
python ultiparser1.18.py
```

Зависимости ставятся сами при запуске (нужен Chrome).

Первый запуск: введите логин/пароль форума → **💾 Сохранить**.
Дальше: **1. Сканировать разделы** → выбрать темы → **2. Скачать темы** →
вкладка «Документы» → **Сформировать документы**.

## Перенос данных из 1.17

```bat
cd ultiparser1.18
python migrate_data.py            :: ищет ultiparser1.17 рядом
python migrate_data.py --src <путь к ultiparser1.17>
```

Копируются структура, чеки, конфиг, куки, даты тем, **история**,
кэш и картинки. Также умеет мигрировать напрямую из 1.14–1.16.

## Тесты

```bat
cd ultiparser1.18\tests
python test_transport.py    :: T1–T7: jar, отказы, harvest-retry, cooldown, parity
python test_features.py     :: plurals, история, diff, картинки, OCR, docx (X1/X2), стражи
```

X1/X2 проверяют новое поведение: слои 1→2→3, весь документ — один абзац,
промт первый, двойных пробелов нет, хвоста нет.

## Структура папки

| Файл | Назначение |
